# PayControl Web v0.1

Frontend React + TypeScript do PayControl.

## Desenvolvimento

```bash
npm install
npm run dev
```

A aplicação abre em `http://localhost:5173` e usa proxy para a API em `http://localhost:5080`.

## Produção

```bash
npm run build
```

## Variáveis

Copie `.env.example` para `.env` caso queira personalizar a URL da API ou desabilitar o modo demonstrativo.
